# LeetCode Patterns (Java)

This repository tracks my interview preparation **by problem-solving patterns**, not by random LeetCode grinding.

## Structure
- `patterns/` — one folder per pattern
  - `README.md` — pattern recognition & pitfalls
  - `template.java` — reusable interview template
  - `variants.md` — common variations
  - `problems/` — runnable Java solutions
- `progress.md` — progress tracking
- `playground/` — quick experiments

## How to run a solution
```bash
javac patterns/02_sliding_window/problems/ExampleProblem.java
java -cp patterns/02_sliding_window/problems ExampleProblem
